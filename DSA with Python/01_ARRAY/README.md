# 🧠 Problem-Solving Rule

For important problems, follow:

```text
Understand
    ↓
Example / Dry Run
    ↓
Brute Force
    ↓
Code
    ↓
Time & Space Complexity
    ↓
Find Better Approach
    ↓
Optimized Code
    ↓
Dry Run Again
    ↓
Identify Pattern
    ↓
Solve Similar Problems
```

> **Don't memorize the solution. Understand the pattern.**

> **If I cannot code it myself, I don't consider the topic complete.**
